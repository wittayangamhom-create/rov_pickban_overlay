# Skins

ภาพพื้นหลังที่ออกแบบเอง แยกเป็นส่วนบนและส่วนล่างของแต่ละหน้า

| ไฟล์ | ใช้ที่ไหน |
|---|---|
| `overlay-top.*` | แถบบนของ overlay (ban, score, timer) |
| `overlay-bottom.*` | แถบล่างของ overlay (การ์ด pick) |
| `result-top.*` | หน้า result ครึ่งบน (ทีมน้ำเงิน) |
| `result-bottom.*` | หน้า result ครึ่งล่าง (ทีมแดง) |

อัปโหลดได้จาก Control Panel หรือวางไฟล์ไว้ที่นี่เองก็ได้
รองรับ `.png` `.jpg` `.webp` ขนาดไม่เกิน 8 MB

ออกแบบที่อัตราส่วน 16:9 ระบบจะย่อขยายให้พอดีทั้ง 1080p และ 1440p
พื้นที่ที่ต้องการให้เห็นรูปฮีโร่หรือฉากหลัง ให้ทำเป็นพื้นที่โปร่งใส (PNG)
