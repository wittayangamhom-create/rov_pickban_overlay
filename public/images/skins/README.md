# Skins

ภาพพื้นหลังที่ออกแบบเอง แยกเป็นส่วนบน/ส่วนล่าง และ **แยกตามขนาดจอ**

อัปโหลดได้จากหน้า Design (`http://127.0.0.1:3000/design`) หรือวางไฟล์ไว้ที่นี่เองก็ได้
รองรับ `.png` `.jpg` `.webp` ขนาดไฟล์ไม่เกิน 8 MB ต่อไฟล์

ระบบจะหยิบชุดที่ตรงกับขนาดที่เลือกอยู่ใน Control Panel
ถ้าใช้แค่ขนาดเดียว อัปโหลดแค่ชุดนั้นก็พอ

## ขนาดที่ต้องทำ

ภาพจะถูก **ยืดเต็มพื้นที่** ไม่ได้ครอบตัด ถ้าสัดส่วนไม่ตรงกับที่ระบุ ภาพจะบิด
แต่ละพื้นที่เป็นแถบยาว **ไม่ใช่ 16:9**

### ชุด 1080p (Browser Source 1920 x 1080)

| ไฟล์ | ใช้ที่ไหน | ขนาด | สัดส่วน |
|---|---|---|---|
| `overlay-top-1080.*` | แถบบนของ overlay (ban, ชื่อทีม, score, timer) | 1920 x 166 | 11.57 : 1 |
| `overlay-bottom-1080.*` | แถบล่างของ overlay (การ์ด pick 10 ช่อง) | 1864 x 360 | 5.18 : 1 |
| `result-top-1080.*` | หน้า result ครึ่งบน (ทีมน้ำเงิน) | 1920 x 540 | 3.56 : 1 |
| `result-bottom-1080.*` | หน้า result ครึ่งล่าง (ทีมแดง) | 1920 x 540 | 3.56 : 1 |

### ชุด 1440p (Browser Source 2560 x 1440)

| ไฟล์ | ใช้ที่ไหน | ขนาด | สัดส่วน |
|---|---|---|---|
| `overlay-top-1440.*` | แถบบนของ overlay | 2560 x 220 | 11.64 : 1 |
| `overlay-bottom-1440.*` | แถบล่างของ overlay | 2476 x 520 | 4.76 : 1 |
| `result-top-1440.*` | หน้า result ครึ่งบน | 2560 x 720 | 3.56 : 1 |
| `result-bottom-1440.*` | หน้า result ครึ่งล่าง | 2560 x 720 | 3.56 : 1 |

## ทำไมต้องแยกไฟล์

- **overlay แถบล่าง** สัดส่วนต่างกันจริง (5.18 กับ 4.76) เพราะ layout 1440p ถูกจูนมาต่างหาก
  ไม่ได้ย่อขยายมาจาก 1080p ใช้ไฟล์เดียวจะยืดไม่เท่ากัน
- **หน้า result** สัดส่วนเท่ากัน (3.56 ทั้งคู่) แต่ตอน 1440p ถูกขยาย 4/3
  ภาพ 1080p ที่เอาไปใช้จะถูกขยายตามแล้วเบลอ ทำไฟล์ 2560 x 720 จะคมกว่า
- **overlay แถบบน** ต่างกันแค่ 0.6% จะทำไฟล์เดียวแล้วอัปโหลดสองช่องก็ได้

ทำพื้นที่โปร่งใส (PNG) ตรงที่อยากให้เห็นรูปฮีโร่และฉากหลังทะลุขึ้นมา

> ตัวเลขพวกนี้อ้างอิงจาก layout ปัจจุบัน ถ้าแก้ขนาดใน `public/css/overlay.css`,
> `overlay-1440.css` หรือ `result.css` ต้องแก้ทั้งที่นี่และใน `public/js/design.js` ด้วย
