# Skins

ภาพพื้นหลังที่ออกแบบเอง แยกเป็นส่วนบนและส่วนล่างของแต่ละหน้า

อัปโหลดได้จากหน้า Design (`http://127.0.0.1:3000/design`) หรือวางไฟล์ไว้ที่นี่เองก็ได้
รองรับ `.png` `.jpg` `.webp` ขนาดไฟล์ไม่เกิน 8 MB

## ขนาดที่ต้องทำ

ภาพจะถูก **ยืดเต็มพื้นที่** ไม่ได้ครอบตัด ถ้าสัดส่วนไม่ตรงกับที่ระบุ ภาพจะบิด
แต่ละพื้นที่เป็นแถบยาว **ไม่ใช่ 16:9**

| ไฟล์ | ใช้ที่ไหน | 1080p | 1440p |
|---|---|---|---|
| `overlay-top.*` | แถบบนของ overlay (ban, ชื่อทีม, score, timer) | 1920 x 166 | 2560 x 220 |
| `overlay-bottom.*` | แถบล่างของ overlay (การ์ด pick 10 ช่อง) | 1864 x 360 | 2476 x 520 |
| `result-top.*` | หน้า result ครึ่งบน (ทีมน้ำเงิน) | 1920 x 540 | ไฟล์เดียวกัน |
| `result-bottom.*` | หน้า result ครึ่งล่าง (ทีมแดง) | 1920 x 540 | ไฟล์เดียวกัน |

หน้า result ย่อขยายทั้งหน้าเท่ากันหมด ไฟล์เดียวจึงพอดีทั้งสองขนาด

overlay แถบบนสัดส่วนต่างกันแค่ 0.6% (11.57 กับ 11.64) ใช้ไฟล์เดียวได้
แถบล่างต่างกันราว 9% (5.18 กับ 4.76) เพราะ layout 1440p ถูกจูนมาต่างหาก
ไม่ได้ย่อขยายมาจาก 1080p ถ้าต้องการความเป๊ะให้ทำแยกตามขนาดที่ใช้ออกอากาศจริง

ทำพื้นที่โปร่งใส (PNG) ตรงที่อยากให้เห็นรูปฮีโร่และฉากหลังทะลุขึ้นมา

> ตัวเลขพวกนี้อ้างอิงจาก layout ปัจจุบัน ถ้าแก้ขนาดใน `public/css/overlay.css`,
> `overlay-1440.css` หรือ `result.css` ต้องแก้ทั้งที่นี่และใน `public/js/design.js` ด้วย
